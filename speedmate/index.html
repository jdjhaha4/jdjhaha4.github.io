SpeedMate - 자전거 속도계

GPS로 자전거 속도·거리·주행 시간을 실시간 측정하는 간편한 속도계

Google Play에서 설치 개인정보처리방침

SpeedMate는 자전거 라이딩 중 현재 속도를 크고 선명하게 보여주는 GPS 속도계 앱입니다.

복잡한 설정 없이 앱을 열고 '라이딩 시작'만 누르면 바로 측정이 시작됩니다.

주요 기능

  • 실시간 속도(km/h)를 큰 숫자로 표시
  • 최고 속도, 평균 속도 기록
  • 이동 거리(km)와 주행 시간 측정
  • 시작 / 일시정지 / 계속하기 / 종료 제어
  • 라이딩 중 화면이 꺼지지 않도록 유지
  • GPS 신호 흔들림을 보정해 안정적인 속도 표시

이런 분께 추천해요

  • 자전거 속도계를 따로 구입하지 않고 스마트폰으로 속도를 확인하고 싶은 분
  • 출퇴근, 운동 라이딩의 거리와 시간을 간단히 기록하고 싶은 분

개인정보 보호

  • 위치 정보는 속도와 거리 계산을 위해 기기 안에서만 사용되며, 서버로 전송하거나 저장하지 않습니다.
  • 회원가입이 필요 없습니다.

안내

  • 정확한 측정을 위해 하늘이 트인 야외에서 사용해 주세요.
  • 주행 중에는 화면을 조작하지 말고 안전에 유의해 주세요.
  • 앱 하단에 광고가 표시됩니다.

자주 묻는 질문

자전거 속도계를 따로 사지 않아도 되나요?

SpeedMate는 스마트폰 GPS로 현재 속도, 최고·평균 속도, 이동 거리, 주행 시간을 측정합니다.

회원가입이 필요한가요?

아니요. 앱을 열고 '라이딩 시작'만 누르면 바로 측정합니다.

위치 정보가 서버로 전송되나요?

아니요. 위치 정보는 속도와 거리 계산을 위해 기기 안에서만 사용하며 서버로 전송하거나 저장하지 않습니다.
