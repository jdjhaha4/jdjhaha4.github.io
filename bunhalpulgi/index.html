분할풀기 - 7z zip rar 분할 압축 해제

7z·zip·rar 분할 압축(.001 / .part1.rar)을 한 번에 골라 풀고, 다 쓴 조각은 자동으로 정리하는 압축 해제 앱

Google Play에서 설치 개인정보처리방침

메일·메신저·AI 채팅에서 용량 제한 때문에 나눠 받은 압축 파일을 휴대폰에서 한 번에 푸는 앱입니다.

이름.7z.001, .002 …나 이름.part1.rar, .part2.rar … 조각을 한꺼번에 고르면 같은 압축끼리 알아서 묶고, 조각이 다 있는지 확인한 뒤 바로 풀어 줍니다.

주요 기능

  • 조각 한 번에 고르기: 여러 압축의 조각이 섞여 있어도 이름을 보고 같은 압축끼리 묶기. 파일 앱의 공유·다음으로 열기도 지원
  • 덜 받은 조각 미리 확인: 머리말·꼬리말을 읽어 아직 받는 중인지, 몇 번 조각이 빠졌는지 풀기 전에 표시
  • 바로 풀기: 조각을 합친 임시 파일 없이 바로 풀어 저장 공간 부담이 적음. 화면을 꺼도 끝까지 풀고 알림
  • 비밀번호 압축: 암호가 걸린 7z·rar은 비밀번호를 물어보고 풀기
  • 조각 자동 정리: 풀기에 성공하면 다 쓴 조각을 지우기(실패하면 지우지 않음)
  • 결과 바로 쓰기: Download/분할풀기 폴더에 저장, 결과 화면에서 열기·공유·폴더 열기

지원하는 형식

  • 7z 분할: 이름.7z.001, .002 …
  • zip 분할: 이름.zip.001 … / 이름.z01, .z02 … + 이름.zip
  • rar 분할: 이름.part1.rar, .part2.rar … / 이름.rar + .r00, .r01 …
  • 분할되지 않은 7z, zip, rar 파일 하나
  • RAR4·RAR5, 7z 비밀번호(AES), 윈도우에서 만든 한글 파일 이름(zip)

이런 분께 추천해요

  • 큰 파일을 여러 조각으로 나눠 받는 분
  • 휴대폰에서 7z, rar 파일을 자주 푸는 분
  • 압축 앱의 잦은 전면 광고가 불편했던 분
  • 다 푼 조각 정리가 귀찮았던 분

자주 묻는 질문

어떤 파일을 풀 수 있나요?

7z·zip·rar의 분할 압축(.001, .part1.rar, .z01 등)과 분할되지 않은 7z·zip·rar 파일을 풀 수 있습니다. 비밀번호가 걸린 7z·rar도 풀 수 있습니다.

조각을 하나씩 열어야 하나요?

아니요. 받은 조각을 한꺼번에 고르면 같은 압축끼리 알아서 묶어 풉니다. 덜 받은 조각이 있으면 풀기 전에 알려 드립니다.

파일이 서버로 전송되나요?

아니요. 압축 풀기는 모두 기기 안에서 이루어지며, 파일과 내용은 어디에도 전송하지 않습니다.

모든 파일 접근 권한이 필요한가요?

아니요. 사용자가 직접 고르거나 공유한 파일만 읽습니다. 푼 파일은 Download/분할풀기 폴더에 저장됩니다.

회원가입이 필요한가요?

아니요. 로그인이나 회원가입 없이 바로 쓸 수 있습니다.
